# Task Target: Design Security and Read Sub-commands

## Objective
Design the architecture and SKILL.md for two new sub-commands: `read` (knowledge synthesis) and `security` (runtime guard).

## Requirements
1. `read`: Must ingest user documents, extract novel information, deduplicate against existing library knowledge, and supplement with web research before saving to `.references/`.
2. `security`: Must provide a runtime assessment mechanism to intercept high-risk operations (especially latent injections that escaped ingestion filters) before they cause irreversible damage (e.g., file deletion).

## Constraints
Must integrate seamlessly into the existing `task-ai` lifecycle and respect the CQRS and Stdlib-only principles.
