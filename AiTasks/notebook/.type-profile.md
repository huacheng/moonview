# Type Profile: software

## Domain Classification
- **Assigned type**: `software`
- **Classification**: single
- **Confidence**: high
- **Rationale**: 本任务是构建一个 Web 应用（前端 notebook 界面 + 后端 Claude Agent SDK 服务），属于典型的全栈软件开发
- **Refinement log**:
  - 2026-02-18 research: initial classification based on .target.md — web application with frontend UI + backend API

## Phase Intelligence
- **plan**: Web 应用架构设计、前后端分离模式、WebSocket 实时通信、HTML 文件格式设计
- **verify**: 单元测试 (Jest/Vitest)、E2E 测试 (Playwright)、API 接口测试
- **check**: 代码质量 (ESLint/TypeScript)、安全性 (API key 管理)、性能 (流式响应延迟)
- **exec**: TypeScript/React 前端、Node.js 后端、Claude Agent SDK 集成

## Domain Methodology
- **Design approach**: 前后端分离，WebSocket 实时通信，cell-based notebook UI
- **Key tools**: TypeScript, React, Node.js, Claude Agent SDK, WebSocket
- **Workflow**: 需求分析 -> 架构设计 -> 后端 API -> 前端 UI -> HTML 导出 -> 重放引擎

## Verification Standards
- **Testing approach**: 单元测试 + 集成测试 + E2E 测试
- **Quality metrics**: TypeScript 类型安全、测试覆盖率 > 70%
- **Acceptance criteria**: 能创建 notebook、执行 cell、导出 HTML、在另一台机器上重放

## Implementation Patterns
- **Common patterns**: 组件化 UI、事件驱动通信、MIME bundle 输出格式
- **Known pitfalls**: WebSocket 断连处理、大输出的流式渲染、API key 安全
- **Tool chain**: npm/pnpm, TypeScript, React, Express/Fastify, ws

## Audit Adaptation
- **Security**: API key 不可暴露到前端或 HTML 导出中
- **Architecture**: 前后端清晰分离，notebook 文件格式可扩展
- **Performance**: 流式输出、大文件处理
- **Extensibility**: 支持自定义 cell 类型、插件
- **Consistency**: 统一的 cell/output 数据模型
- **Correctness**: 重放执行结果与原始执行一致
