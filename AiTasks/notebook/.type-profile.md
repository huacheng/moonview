# Type Profile: software

## Domain Classification
- **Assigned type**: `software`
- **Classification**: single
- **Confidence**: high
- **Rationale**: 全栈 Web 应用（React 前端 + Node.js 后端 + tmux 进程管理），属于典型软件开发
- **Refinement log**:
  - 2026-02-18 research: initial classification — web application with frontend UI + backend API
  - 2026-02-18 re-plan: architecture pivoted from Agent SDK to tmux + Claude Code interactive mode

## Phase Intelligence
- **plan**: tmux 进程管理、JSONL 流式解析、WebSocket 实时通信、reveal.js 嵌入、d3.js 可视化、Git 自动集成、单文件 HTML 打包
- **verify**: 单元测试 (Vitest)、E2E 测试 (Playwright)、tmux 集成测试
- **check**: 代码质量 (ESLint/TypeScript)、安全性 (tmux 权限管理)、性能 (流式渲染延迟)
- **exec**: TypeScript/React 前端、Node.js + tmux 后端、reveal.js Slide、d3.js 图表

## Domain Methodology
- **Design approach**: 前后端分离，tmux 进程管理，JSONL 文件监控，WebSocket 实时通信
- **Key tools**: TypeScript, React, Zustand, Node.js, tmux, simple-git, reveal.js, d3.js, Zod
- **Workflow**: 脚手架 → 数据模型 → tmux 后端 → WebSocket → 前端 UI → Git → HTML 导出 → Slide → 重放 → 批注

## Verification Standards
- **Testing approach**: 单元测试 + 集成测试 + E2E 测试
- **Quality metrics**: TypeScript 类型安全、核心路径测试覆盖
- **Acceptance criteria**: tmux 执行 cell、JSONL 捕获、HTML 双 Tab 导出、重放执行

## Implementation Patterns
- **Common patterns**: cell-based UI、事件驱动通信、JSONL 流式解析、tmux PTY 注入
- **Known pitfalls**: tmux send-keys 空闲状态不提交 (#24108)、JSONL 格式版本变化、大 HTML 文件体积
- **Tool chain**: pnpm, TypeScript, React, Express, ws, tmux, simple-git, chokidar

## Audit Adaptation
- **Security**: tmux 使用 `--dangerously-skip-permissions`，需限制在受控环境
- **Architecture**: 前后端清晰分离，notebook 格式可扩展 (cells + slide + annotations)
- **Performance**: JSONL 流式解析、WebSocket 实时推送、大输出虚拟滚动
- **Extensibility**: cell 类型可扩展 (prompt/markdown/visualization)、批注系统
- **Consistency**: Zod schema 统一数据验证
- **Correctness**: 重放执行与原始执行使用相同 prompt/metadata
