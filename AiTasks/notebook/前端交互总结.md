## 二、项目目录结构

```
project/                        ← 项目根目录
  .index.json                   ← 项目元数据
  .deliverables/                ← 交付物目录（右侧面板管理，左侧不可见）
  .worktrees/                   ← git worktree 存放（不可见）
    task-{slug}/
  .git/                         ← git 仓库（不可见）
  {slug}/                       ← notebook 目录（每个 notebook 一个）
    {slug}.notebook.json        ←   notebook 文件
    .working/                   ←   任务工作文件
  readme.md                     ← 普通文件（自由创建）
```

**dotfile 可见性规则** (服务端 `isVisibleEntry`):
- 非点开头文件/目录 → 可见
- `.index.json` → 可见（白名单精确匹配）
- `*.notebook.json` → 可见（后缀匹配）
- 其他点文件（`.git/`, `.deliverables/`, `.worktrees/`, `.working/`）→ 隐藏

## 三、Store 状态管理

Zustand store，由 6 个 slice 组合：`authSlice` / `notebookSlice` / `sidebarSlice` / `projectSlice` / `uiSlice` / `wsSlice`

### 3.1 uiSlice 状态

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `activeTab` | `'notebook'` | `'notebook' \| 'slice' \| 'git'` |
| `gitTabOpen` | `false` | Git history 标签是否激活 |
| `sessionNotice` | `null` | 显示在 WelcomeScreen 的会话警告 |
| `latency` | `null` | RTT 延迟 (ms) |
| `creatingNotebook` | `false` | 显示 NotebookCreationPanel |
| `wsReconnectExhausted` | `false` | 所有重连尝试已耗尽 |
| `openFiles` | `{}` | `Record<tabId, {path, source, sessionId, loading?}>` |
| `activeFileTabId` | `null` | 当前激活的文件标签 ID |
| `leftSidebarSplitRatio` | `0.5` | 侧边栏上下分隔比例 (0.2–0.8) |
| `fileViewerMaximized` | `false` | FileViewer 全屏状态 |
| `sidebarWidth` | `272` | 侧边栏宽度 px (180–500) |
| `rightPanelWidth` | `300` | 右侧面板宽度 px (180–500) |
| `rightPanelOpen` | `true` | 右侧面板展开/收起 |
| `rightPanelSplitRatio` | `0.5` | （当前未使用） |

**文件标签 ID 格式**: `"{source}::{path}"`，如 `"workspace::src/main.py"`, `"library::ref.pdf"`, `"deliverables::report.docx"`

**Key actions:**
- `openFileTab({path, source, sessionId})` — 添加到 openFiles + 设为 active + loading=true
- `closeFileTab(tabId)` — 移除 + 激活下一个剩余标签或 null
- `setActiveFileTab(tabId)` — 切换激活标签
- `deactivateFileTab()` — 设 activeFileTabId=null 但不关闭标签
- `closeAllFileTabs()` — 清空所有文件标签
- `setFileTabLoading(tabId, bool)` — 更新 loading 标记
- `toggleFileViewerMaximized()` — 切换 `.app-body--fv-maximized`
- `setRightPanelOpen(bool)` — 直接设置面板展开状态
- `toggleRightPanel()` — 翻转面板展开状态

### 3.2 notebookSlice 状态

| 字段 | 说明 |
|------|------|
| `notebook` | 完整 Notebook 对象或 null |
| `sliceLoading` | slice 生成加载状态 |
| `notebookLoading` | notebook 恢复加载状态 |
| `openNotebooks` | `Record<id, {notebook, sessionId, scrollY}>` |
| `activeNotebookTabId` | 当前激活的 notebook 标签 ID |
| `streamBuffer` | `Record<cellId, {text, thinking}>` — 实时流内容 |

**Key behaviors:**
- `updateCellSource()` — 自适应同步：max(200ms, latency×3) 防抖后发送 WS `update_cell_source`
- `submitPrompt()` — 创建新 prompt cell → 追加到 notebook → 立即 `executeCell()`
- `appendStreamDelta()` — 累积流式 chunk 到 streamBuffer
- `flushStreamBuffer()` — `execution_complete` 时清空 buffer

### 3.3 sidebarSlice 状态

| 字段 | 说明 |
|------|------|
| `sidebarOpen` | 侧边栏可见性 |
| `notebookList` | notebook 列表 |
| `notebookListLoading` | 加载状态 |
| `activeNotebookId` | 当前打开的 notebook ID |
| `workspaceDir` | 工作空间目录路径 |

**Key behaviors:**
- `fetchNotebookList()` — 最多重试 3 次（600ms/1200ms 退避）；合并 localStorage 缓存标题；清理过期 key
- `restoreNotebook()` — 先检查 localStorage 即时渲染，再 POST 到 API；404 时清缓存
- `deleteNotebook()` — 乐观删除 + 清理所有 cell 草稿缓存
- `importNotebookFile()` — 支持 `.json` 和 `.zip` bundle

### 3.4 projectSlice 状态

| 字段 | 说明 |
|------|------|
| `projects` | 项目列表 |
| `projectsLoading` | 加载状态 |
| `activeProjectId` | 当前选中项目 ID |
| `activeProjectPath` | 当前项目路径 |
| `sidebarLevel` | `'L1' \| 'L2'` |
| `fileBrowserPath` | 文件浏览器当前子路径 |

## 四、模块交互流程

### 4.1 认证模块

| 操作 | 组件 | 流程 |
|------|------|------|
| 检查认证 | App | mount → `checkAuthStatus()` → GET `/api/auth/status` |

| Token 验证 | authSlice | `checkAuthStatus()` 内对已存 token 调 `/api/auth/verify` |

### 4.2 项目管理（ProjectSidebar — L1）

| 操作 | 触发 | 流程 |
|------|------|------|
| 加载项目列表 | mount | `fetchProjects()` → GET `/api/projects` |
| 新建项目 | "New Project" 表单 | `createProject(title)` → POST `/api/projects` → 刷新列表 |

| 返回项目列表 | L2 返回按钮 | `goBackToProjectList()` → `sidebarLevel='L1'` |

### 4.3 项目文件（ProjectSidebar — L2 上半区）

仅在 `sidebarLevel='L2'` 时显示。**显示项目根目录**（无 `initialPath` 限制）。

| 操作 | 触发 | 流程 |
|------|------|------|
| 浏览目录 | 面包屑 + 文件夹点击 | FileSection 内部 `setSubPath()` |
| 打开 Notebook | 点击 `.notebook.json` | POST `/api/notebooks/open-by-path` → `openNotebookTab()` + `subscribeToSession()` |
| 打开文件预览 | 点击其他文件 | `openFileTab({path, source:'workspace', sessionId})` → 中心区 FileViewer |
| 新建 Notebook | "+ New Notebook" 按钮 | `createNotebook(projectId, title)` → POST `/api/projects/{id}/notebooks` |
| 上传文件 | 按钮 / 拖入 | FormData POST + progress |
| 新建文件/夹 | 按钮 → 输入名 | POST `/files/new-file` 或 `/files/mkdir` |
| 删除 | 二次确认 | DELETE `/files?path=...`（`MEMORY.md` 不可删除） |
| 下载 | 单文件 / 全部 | GET `/files/download` 或 `/files/zip` |
| 拖出到 prompt | 非 notebook 文件 | 拖拽 `[file: path]` 到 textarea |
| 自动刷新 | 定时器 | 10s 轮询（page visible 时） |

Library 是全局知识库，**不受 L1/L2 切换影响，始终显示**。与上半区之间有可拖拽分隔条。

| 操作 | 触发 | 流程 |
|------|------|------|
| 浏览目录 | 面包屑 + 文件夹点击 | FileSection 内部 `setSubPath()` |
| 打开文件预览 | 点击文件 | `openFileTab({path, source:'library', sessionId:''})` → 中心区 FileViewer |

| 拖出到 prompt | 任意文件 | 拖拽 `[file: path]` 到 textarea（需 `workspaceDir` 计算相对路径） |
| 自动刷新 | 定时器 | 10s 轮询 |
| 调整分隔比例 | 拖拽分隔条 | `setLeftSidebarSplitRatio(0.2~0.8)` |

### 4.4 Notebook 标签管理（多标签系统）

**三种标签类型：**

| 类型 | 标识 | 激活条件 | 点击动作 | 关闭动作 |
|------|------|----------|----------|----------|
| Notebook | `openNotebooks[id]` | `id === activeNotebookTabId && !gitTabOpen && !hasActiveFile` | `closeGitTab()` + `deactivateFileTab()` + `setActiveNotebookTab(id)` | `closeNotebookTab(id)` |
| Git | 固定（有 activeProject 时） | `gitTabOpen && !hasActiveFile` | `deactivateFileTab()` + `openGitTab()` | `closeGitTab()` |
| File | `openFiles[tabId]` | `tabId === activeFileTabId` | `setActiveFileTab(tabId)` | `closeFileTab(tabId)` |

**标签标题截断**: 最长 20 字符，超出显示 `…`，鼠标悬停 `title` 显示完整名称。

> **关键行为**: 切换 notebook/git tab 时自动 `deactivateFileTab()`，避免 FileViewer 挡住其他视图。但文件标签不关闭，可随时再激活。

### 4.5 Notebook 主体

| 操作 | 组件 | 流程 |
|------|------|------|
| 发送 prompt | NotebookInputBar | 输入文字 → Ctrl+Enter 或 ▶ → `submitPrompt(source)` → 创建 cell + `executeCell()` |
| 附件上传 | NotebookInputBar + 按钮 | POST `/api/notebooks/{sessionId}/files` → `[file: name]` 引用插入；上传状态 4s 后消失 |
| 拖入文件引用 | textarea onDrop | 拖入 `[file: path]` 文本 |
| 批注转发 | window 事件 | `nb:appendPrompt` CustomEvent → 追加到 textarea |
| Save | NotebookStatusBar | `saveNotebook()` → WS `save_notebook` |
| Export | NotebookStatusBar | GET `/api/notebooks/{sessionId}/export-zip` → 下载 |
| Slice 视图切换 | NotebookStatusBar | `setActiveTab('slice')` ↔ `setActiveTab('notebook')` |
| 自动滚底 | useEffect | cells.length 变化 → 滚到底部 ref |

### 4.6 Cell 输出

| 输出类型 | 组件 | 显示方式 |
|----------|------|---------|
| Thinking | ThinkingPanel | 可折叠，默认收起；运行中由 StreamingThinking 替代（20ms 轮询 DOM 更新） |

### 4.10 FileViewer（文件查看器）

#### 4.10a 打开/关闭生命周期

| 操作 | 流程 |
|------|------|
| 打开 | `openFileTab({path, source, sessionId})` → 标签 loading=true → `useFileStream()` 建立 WS 通道 |
| 关闭 | StatusBar ✕ 或标签 × → `closeFileTab(tabId)` → 自动激活下一个标签或 null |
| 最大化 | StatusBar ⛶ → `toggleFileViewerMaximized()` → `.app-body--fv-maximized` 隐藏左右侧栏 |
| 切标签 | 点击其他文件标签 → `setActiveFileTab(tabId)` → 复用同一 FileViewer 容器 |

#### 4.10b 格式支持与渲染

| 格式 | format 值 | 渲染方式 | 可编辑 |
|------|-----------|----------|--------|
| 纯文本 | `text` | `<pre>` / ReactMarkdown (.md) / JSON 格式化 (.json) | ✓ |
| HTML | `html` | `dangerouslySetInnerHTML` + DOMPurify 消毒 | ✓ |
| PDF | `pdf-binary` | react-pdf Document/Page，LazyPage 惰性加载 | ✗ |
| DOCX | `docx-binary` | docx-preview `renderAsync()` | ✗ |
| XLSX | `xlsx-binary` | SheetJS `XLSX.read()` + `sheet_to_html()`，多 sheet 标签切换 | ✗ |
| PPTX | `pptx-binary` | 下载占位符（Blob + createObjectURL） | ✗ |

**canEdit 判定**: `format !== null && !format.endsWith('-binary') && format !== 'unsupported'`

#### 4.10c PDF 专有控件

| 控件 | 位置 | 行为 |
|------|------|------|
| 页码指示器 | StatusBar 中部 | `{pdfPage} / {pdfPages}` — 基于 IntersectionObserver (threshold: 0.5) 跟踪可见页 |
| 缩小 `−` | StatusBar | `setPdfScale(s - 0.25)`，下限 0.5 |
| 放大 `+` | StatusBar | `setPdfScale(s + 0.25)`，上限 3.0 |
| 缩放百分比 | StatusBar | 显示 `{Math.round(scale * 100)}%` |

**LazyPage 机制**:
- 惰性加载: `IntersectionObserver(rootMargin: '2500px')` — 进入视口前 ≈3 页开始渲染，渲染后不卸载
- 可见性跟踪: 第二个 `IntersectionObserver(threshold: 0.5)` — 持续追踪哪些页可见，报告最小页码

#### 4.10d 批注系统

| 操作 | 组件 | 流程 |
|------|------|------|
| 选中文字 | FileViewerRender mouseUp | 显示 FileSelectionFloat（相对于容器定位） |
| 添加批注 | Float 按钮 (−/⇄/?/+) | 创建 annotation `{type, selected_text, content, author, timestamp}` |
| 查看批注列表 | FileAnnotationDropdown | 右上角徽章（计数），展开面板 |
| 发送单条到 prompt | 批注卡片 Send | `onSendToPrompt()` → `nb:appendPrompt` CustomEvent |
| 发送全部到 prompt | "Send All" | 汇总所有批注文本发送 |
| 删除批注 | 批注卡片 × | `removeAnnotation()` |
| 持久化 | useAnnotationPersistence | L1: localStorage 50ms 防抖 / L2: WS `annotation-sync` 自适应(max(200ms, latency×3)) |
| 加载 | filePath 变化 | L1: instant localStorage / L2: async `annotation-load` → 取 `updatedAt` 更新的版本 |

#### 4.10e FileViewerStatusBar 布局

```
┌──────────────────────────────────────────────────────────────────┐
│  filename.pdf    [PDF]   1 / 15   [−] 100% [+]   [Edit] [⛶] [✕] │
│  ↑ name          ↑format  ↑page controls         ↑actions        │

```

- `position: sticky; top: 0; z-index: 10` — 始终可见
- `background: rgba(255,255,255,0.92); backdrop-filter: blur(10px)` — 半透明磨砂

### 4.11 WebSocket 生命周期

| 阶段 | 流程 |
|------|------|
| 连接 | `useWebSocket` mount → `connectWebSocket()` → WSS + token |
| 重连 | 3s 定时检查 → 最多 10 次 → 耗尽显示 banner |
| 心跳 | 每 10s ping → 4s 内无 pong → close |
| 会话切换 | sessionId 变化 → unsubscribe 旧 → subscribe 新 |
| 消息分发 | wsSlice onmessage → switch(type) → 调用 store actions |

**WS 入站消息:**

| 消息类型 | 处理 |
|----------|------|
| `cell_output` | `appendCellOutput()` |
| `cell_stream` | `appendStreamDelta()` |

## 八、持久化（localStorage）

| Key 模式 | TTL | 内容 |
|----------|-----|------|
| `nb-auth-token` | 无 TTL | 认证 token（原始 localStorage） |
| `nb-last-notebook` | 30 天 | 上次打开的 notebook ID |
| `nb-notebook-{id}` | 7 天 | 序列化 notebook 数据 |
| `nb-title-{id}` | 7 天 | 乐观更新的标题 |
| `nb-scroll-{id}` | 7 天 | 滚动位置 (number) |
| `nb-draft-{cellId}` | 7 天 | Cell 草稿文本 |
| `file-content-{nbId}-{path}` | 3 天 (text) / 24 小时 (binary) | 文件内容 + mtime + format |
| `nb-filelist-{baseUrl}-{path}` | 5 分钟 | FileSection 目录列表 |
| `nb-git-{projectId}` | 1 天 | Git history 首 30 条 commit |
| `ann-{nbId}-{filePath}` | 7 天 | 文件批注 |

**配额超限处理**: `QuotaExceededError` 时自动清理 7 天以上过期条目并重试。
**过期 key 清理**: `fetchNotebookList()` 遍历所有 `nb-(notebook|scroll|title)-{id}` key，删除不再存在于服务端的条目。
