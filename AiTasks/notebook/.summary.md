# Summary: notebook

## Objective

研究如何将 Claude Code 置于服务端，在前端以类似 JupyterLab 的 Notebook 界面将输入与输出固化到一个 HTML 文件中。该 HTML 文件可被打包共享，工作流可在另一台机器上再次执行。

## Status

- **Phase**: planning
- **Type**: TBD (awaiting research)

## Key Concepts

- Claude Code 服务端化
- Notebook 式交互界面（类似 JupyterLab）
- 输入/输出固化为 HTML
- 可打包共享、可重放执行
