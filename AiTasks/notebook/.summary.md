# Summary: notebook

## Objective

构建一个类似 JupyterLab 的 Notebook 系统，以 Claude Agent SDK 为"内核"，将交互过程固化为可共享、可重放的 HTML 文件。

## Architecture

- **前端**: React + TypeScript notebook UI，cell-based 界面
- **后端**: Node.js + Claude Agent SDK，WebSocket 实时通信
- **文件格式**: `.notebook.json`（JSON，类似 .ipynb）
- **HTML 导出**: 自包含 HTML，内嵌 notebook 数据 + 重放引擎

## Plan Overview (7 Steps)

1. 项目脚手架 (pnpm monorepo)
2. 共享数据模型 (TypeScript types)
3. 后端 Agent 服务 (SDK + WebSocket)
4. 前端 Notebook UI (React cells)
5. HTML 导出引擎 (自包含)
6. 重放引擎 (跨机器执行)
7. 集成测试 & 文档

## Key Decisions

- Claude Agent SDK `query()` 作为"内核"
- WebSocket 转发 SDK 流式消息
- JSON 格式存储，HTML 为导出衍生物
- 重放需要目标机器运行 server（API 调用需服务端）
