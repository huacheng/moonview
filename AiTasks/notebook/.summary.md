# Summary: notebook

## Status: COMPLETE (11/11 steps)

## What Was Built

JupyterLab-like Notebook system with Claude Code as server-side "kernel" via tmux interactive mode. Interactions persist as `.notebook.json` files and export to self-contained HTML with dual Notebook/Slice tabs.

## Architecture

- **pnpm monorepo**: `packages/shared` (Zod types), `packages/server` (Express+ws+tmux), `packages/web` (React 19+Vite+Zustand)
- **输入**: `tmux send-keys` PTY 层注入 prompt
- **输出**: JSONL 文件监控 (`~/.claude/projects/`) + Stop hook 完成信号
- **Git**: simple-git 自动 commit + diff 提取
- **文件格式**: `.notebook.json`（JSON，含 cells + slice + annotations + assets）
- **HTML 导出**: 自包含单文件，Notebook + Slice 双 Tab，内联 CSS/JS，嵌入重放引擎

## Implementation (11 Steps, 4 Phases)

**Phase 1 — MVP (Steps 1-5)**: 脚手架、数据模型、tmux 管理、WebSocket 服务、前端 UI

**Phase 3 — 演示 (Steps 8-9)**: Slice 生成、重放引擎
