# Summary: notebook

## Objective

构建一个类似 JupyterLab 的 Notebook 系统，将 Claude Code 置于服务端（tmux 交互模式），将交互过程固化为可共享、可重放的 HTML 文件。支持数据可视化、Git 变更追踪、Slide 生成、单文件打包。

## Architecture

- **前端**: React + TypeScript + Zustand，cell-based notebook UI + reveal.js Slide Tab
- **后端**: Node.js + Express + tmux 管理 Claude Code 常驻会话
- **输入**: `tmux send-keys` PTY 层注入 prompt
- **输出**: JSONL 文件监控 (`~/.claude/projects/`) + Stop hook 完成信号
- **Git**: simple-git 自动 commit 每次 cell 执行的文件变更
- **文件格式**: `.notebook.json`（JSON，含 cells + slide + annotations + assets）
- **HTML 导出**: 自包含单文件，Notebook + Slide 双 Tab，内联 CSS/JS/d3/reveal.js

## Key Decisions

- **内核**: tmux + Claude Code 交互模式（零启动开销、上下文自动连续、Pro/Max 订阅）
- **Slide**: reveal.js embedded mode（可嵌入 HTML Tab）
- **可视化**: d3.js v7（SVG 可内联导出）
- **Git**: simple-git（最流行的 Node.js git 库）
- **参考**: ai-cli-online (tmux + node-pty + WebSocket 生产级架构)
