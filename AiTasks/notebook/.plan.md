# Implementation Plan: Claude Code Notebook

## 概述

构建一个类似 JupyterLab 的 Notebook 系统，将 Claude Code 置于服务端作为"内核"（通过 tmux 交互模式），将交互过程固化为可共享、可重放的 HTML 文件。支持数据可视化、Git 变更追踪、Slide 总结生成，以及单文件打包分发。

## 架构决策记录

以下决策经过多轮研究和注释讨论确定（完整讨论链见 `.plan-superseded.md`）：

| 决策 | 选择 | 理由 |
|------|------|------|
| **内核方案** | tmux + Claude Code 交互模式 | Agent SDK 仅支持 API key；`claude -p` 每 cell ~12s 冷启动；tmux 方案零启动开销、上下文自动连续、社区验证充分（ccbot、claudecode-telegram） |
| **输入机制** | `tmux send-keys` PTY 注入 | 在 PTY 层级注入按键，成功触发 Ink 的 onSubmit（社区确认有效） |
| **输出获取** | JSONL 文件监控 + Stop hook | 不解析终端 ANSI 输出；监控 `~/.claude/projects/<hash>/<session>.jsonl` + 注册 Stop hook 写标记文件 |
| **认证** | Pro/Max 订阅（零 API 成本） | tmux 方案使用 Claude Code 原生认证，支持订阅模式 |
| **参考项目** | ai-cli-online | 生产级 tmux + node-pty + WebSocket 架构，后端可直接参考 |
| 包管理器 | pnpm | monorepo 支持 |
| 前端框架 | React + TypeScript + Zustand | cell-based UI + 状态管理 |
| 后端框架 | Express + ws | WebSocket 原生支持 |
| 构建工具 | Vite (前端) + tsx (后端) | 快速开发 |
| Slide 框架 | reveal.js (embedded mode) | 支持 `embedded: true` 嵌入现有页面，Markdown 插件自动解析 |
| 可视化 | d3.js v7 | 通用可视化库，SVG 输出可内联到 HTML |
| Git 操作 | simple-git | 最流行的 Node.js git 库，async/await API |
| Notebook 格式 | JSON (.notebook.json) | 类似 .ipynb，diffable |

## Step 3: 后端 tmux 会话管理 (packages/server)

**目标**: 通过 tmux 管理 Claude Code 交互进程，实现 prompt 注入和输出获取

### 3.1 tmux 会话生命周期 (tmux.ts)

```typescript
import { exec } from 'child_process';
import { promisify } from 'util';
const execAsync = promisify(exec);

class TmuxSession {
  constructor(private sessionName: string, private cwd: string) {}

  async start(): Promise<void> {
    // 创建 tmux 会话，启动 Claude Code
    await execAsync(
      `tmux new-session -d -s ${this.sessionName} -c ${this.cwd} ` +
      `"claude --dangerously-skip-permissions"`
    );
    // 等待 Claude Code 初始化完成（检测 JSONL 文件出现）
    await this.waitForReady();
  }

  async sendPrompt(prompt: string): Promise<void> {
    // 使用 -l 参数发送原文（避免特殊字符被解释）
    await execAsync(
      `tmux send-keys -t ${this.sessionName} -l ${shellEscape(prompt)}`
    );
    // 发送 Enter 触发提交
    await execAsync(
      `tmux send-keys -t ${this.sessionName} Enter`
    );
  }

  async stop(): Promise<void> {
    await execAsync(`tmux kill-session -t ${this.sessionName}`);
  }
}
```

### 3.2 JSONL 文件监控 (jsonl-watcher.ts)

```typescript
import { watch } from 'chokidar';
import { createReadStream } from 'fs';
import { createInterface } from 'readline';

class JsonlWatcher {
  private offset = 0; // 字节偏移

  constructor(
    private jsonlPath: string,
    private onMessage: (msg: any) => void
  ) {}

  start(): void {
    // 监控文件变化
    const watcher = watch(this.jsonlPath, { persistent: true });
    watcher.on('change', () => this.readNewLines());
  }

  private async readNewLines(): Promise<void> {
    // 从上次偏移开始读取新行
    const stream = createReadStream(this.jsonlPath, {
      start: this.offset, encoding: 'utf-8'
    });
    const rl = createInterface({ input: stream });
    for await (const line of rl) {
      if (line.trim()) {
        this.onMessage(JSON.parse(line));
        this.offset += Buffer.byteLength(line + '\n');
      }
    }
  }
}
```

## Step 4: WebSocket 服务 + Notebook 持久化

**目标**: 连接前端与 tmux 后端，管理 Notebook 文件读写

核心功能:
1. **WebSocket 服务**: 接收 `execute_request`，调用 `TmuxSession.sendPrompt()`，将 `JsonlWatcher` 捕获的消息通过 WebSocket 转发给前端
2. **会话管理**: 每个打开的 notebook 对应一个 tmux 会话
3. **Notebook CRUD**: 创建/打开/保存 `.notebook.json` 文件
4. **REST API**: 文件列表、notebook 元数据、导出触发

```typescript
// WebSocket 消息路由
wss.on('connection', (ws) => {
  ws.on('message', async (data) => {
    const msg = JSON.parse(data.toString());
    switch (msg.type) {
      case 'execute_request':
        await session.tmux.sendPrompt(msg.source);
        // JsonlWatcher 会自动将输出转发给 ws
        break;
      case 'save_notebook':
        await fs.writeFile(msg.path, JSON.stringify(notebook, null, 2));
        break;
      case 'export_html':
        const html = await exportToHtml(notebook, msg.options);
        ws.send(JSON.stringify({ type: 'export_complete', html }));
        break;
    }
  });
});
```

**交付物**: 前端可通过 WebSocket 发送 prompt、接收流式输出、保存/加载 notebook

## Step 6: Git 集成

**目标**: 自动追踪每次 Claude Code 交互产生的文件变更

核心功能:
1. **Auto-commit**: 每个 cell 执行完成后，自动 `git add -A && git commit`，commit message 包含 cell ID 和 prompt 摘要
2. **Diff 获取**: 使用 `simple-git` 获取每次 commit 的 diff
3. **GitDiffView 组件**: 在 cell 输出下方显示可折叠的文件变更区域
   - 变更文件列表（点击展开 diff）
   - 使用 `react-diff-viewer` 渲染 unified diff
4. **中间文件嵌入**: Cell 执行过程中产生的 md 文件内容嵌入到 notebook JSON 中

```typescript
// git.ts
import simpleGit from 'simple-git';

async function commitCellExecution(
  git: SimpleGit, cellId: string, prompt: string
): Promise<string> {
  await git.add('-A');
  const summary = prompt.slice(0, 50);
  const result = await git.commit(`[notebook:${cellId}] ${summary}`);
  const diff = await git.diff([`${result.commit}~1`, result.commit]);
  return diff;
}
```

**交付物**: 每次 cell 执行自动产生 git commit，前端可查看 diff

## Step 8: Slide 生成

**目标**: 从 Notebook 内容一键生成 Slide 用于汇报演示

实现方式:
1. **自动摘要**: 遍历所有 cell，提取关键输出（文本摘要 + 可视化图表 + 代码变更）
2. **Slide 结构**: 每个 Slide section 对应一个或多个 cell，包含标题 + 要点
3. **reveal.js embedded**: 使用 `embedded: true` 模式，在 HTML 文件的 Slide Tab 中渲染
4. **多任务总结**: 可合并多个 notebook 的 Slide sections 形成新的综合演示

```typescript
// slide-generator.ts
function generateSlide(notebook: Notebook): SlideSection[] {
  const sections: SlideSection[] = [];

  // 标题页
  sections.push({
    title: notebook.metadata.title,
    content: `Created: ${notebook.metadata.created}`
  });

  // 每个 prompt cell 生成一个 section
  for (const cell of notebook.cells) {
    if (cell.type === 'prompt') {
      sections.push({
        title: extractTitle(cell.source),
        content: summarizeOutputs(cell.outputs),
        cell_refs: [cell.id]
      });
    }
  }

  return sections;
}
```

**Slide 编辑**: Slide 生成后支持再编辑 — 修改标题、调整顺序、添加/删除页面。编辑结果保存到 `.notebook.json` 的 `slide` 字段。

**交付物**: Notebook 可一键生成 Slide，在 HTML 文件的 Slide Tab 中展示

## Step 9: 重放引擎

**目标**: HTML 文件在另一台机器上可连接到本地 server 重新执行

实现方式:
1. HTML 文件中嵌入完整 notebook JSON (prompts + metadata)
2. 内嵌轻量 WebSocket 客户端代码
3. 用户在另一台机器上:
   - 安装并启动 `notebook-ai server`
   - 浏览器打开共享的 HTML 文件
   - 输入 server URL，点击"重放"
   - 逐 cell 重新执行，新输出替换旧输出
   - 新的 git diff 实时显示

```typescript
// 嵌入 HTML 中的重放引擎
async function replay(serverUrl: string) {
  const ws = new WebSocket(serverUrl);
  const notebook = JSON.parse(
    document.getElementById('notebook-data').textContent
  );

  for (const cell of notebook.cells) {
    if (cell.type === 'prompt') {
      updateCellStatus(cell.id, 'running');
      ws.send(JSON.stringify({
        type: 'execute_request',
        cell_id: cell.id,
        source: cell.source
      }));
      await waitForComplete(ws, cell.id);
      updateCellStatus(cell.id, 'completed');
    }
  }
}
```

**交付物**: HTML 文件可连接远程 server 重新执行所有 cell

## Step 10: 批注与语音批注 (后续扩展)

**目标**: 支持对 Notebook 和 Slide 添加文本/语音批注

核心功能:
1. **文本批注**: 选中 cell 输出区域的文字或 Slide 页面，添加文字评论
2. **语音批注**: 使用 MediaRecorder API 录制语音，base64 编码后附加到批注
3. **语音转文字**: 使用 Web Speech API (SpeechRecognition) 同步生成文字转录
4. **批注 → 任务**: 会议讨论中的批注可一键转为下一步工作任务（生成新的 prompt cell）

```typescript
// 语音批注录制
async function recordVoiceAnnotation(targetCellId: string) {
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  const recorder = new MediaRecorder(stream);
  const chunks: Blob[] = [];

  recorder.ondataavailable = e => chunks.push(e.data);
  recorder.onstop = () => {
    const blob = new Blob(chunks, { type: recorder.mimeType });
    const reader = new FileReader();
    reader.onload = () => {
      addAnnotation({
        target_cell: targetCellId,
        type: 'voice',
        audio_base64: reader.result as string, // data:audio/webm;base64,...
        transcript: currentTranscript, // 来自 SpeechRecognition
      });
    };
    reader.readAsDataURL(blob);
  };

  recorder.start();
}
```

**注意**: 语音批注会增加 HTML 文件大小（30 秒 ~480KB base64）。大量语音批注的场景需要考虑文件大小优化。

**交付物**: 可对 cell 添加文本/语音批注，批注可转为工作任务

## 风险与缓解

| 风险 | 缓解措施 |
|------|----------|
| tmux send-keys 不提交 (Issue #24108) | 添加 retry 机制；备选方案 C 作为 fallback |
| JSONL 文件格式随版本变化 | 解析层做宽松匹配，关键字段缺失时降级处理 |
| Claude Code 交互式权限提示阻塞 | 使用 `--dangerously-skip-permissions` 启动 |
| 大 HTML 文件（语音批注多） | 限制单个 notebook 批注数量或提供精简导出选项 |
| WebSocket 断连 | 指数退避自动重连 + 请求队列缓冲 |
| tmux 会话异常退出 | 健康检查 + 自动重建会话 |
| 重放一致性 | LLM 输出不确定性是固有特性，提示用户预期差异 |
| reveal.js 内联体积 | 仅包含 core + markdown plugin，约 100KB gzip |
