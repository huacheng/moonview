# task-ai 目录结构重组实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 task-ai 的路径体系从单一的 `AiTasks/` 目录，拆分为三层结构（workspace root / library / notebook .working/），并引入 `NB_WORKSPACES_ROOT` 和 `NB_WORKSPACES_LIBRARY` 环境变量。

**Architecture:** 所有 SKILL.md 文件和主命令文档均为纯文本编辑任务——将旧路径引用批量替换为新的三层路径体系。`commands/ai-cli-task.md` 是最复杂的文件（主文档，包含目录结构定义）；其余文件主要做路径引用替换。报告文件 `.report.md` 写入位置从 `.working/` 改为 `[deliverables-dir]/`；共享资料（type-registry、plugin-registry、experiences、references、type-profiles）全部迁移到 `$NB_WORKSPACES_LIBRARY`。

**Tech Stack:** 文本编辑（Edit 工具）+ grep 验证 + git commit
